# Smart Tails Game

Створено за допомогою фреймворку SwiftUI. На розробку проєкту знадобилося близько 3 тижнів.

Ідея була взята з уже існуючого проєкту, який свого часу не був завершений. Я вирішив повернутися до цієї ідеї, переробити її та використати як практику для розвитку навичок в iOS-розробці.

У результаті вийшла досить цікава та повноцінна гра, яка стала хорошою практикою роботи зі SwiftUI, анімаціями, екранами, таймерами та ігровою логікою.
